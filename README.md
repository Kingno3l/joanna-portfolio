# joanna-portfolio

Professional portfolio and online CV of **Joanna Olayemi Stephen** — Educator, Researcher, Educational Consultant, and Founder of Exceptional Roots Learning.

## Features
- **Modern Responsive Design**: Accessible, clean typography, responsive layouts, and zero-overflow grid architecture.
- **Interactive Contact System**: Dual contact points (bottom section and slide-in modal) protected by Cloudflare Turnstile bot defense.
- **Backend & Database**: Submissions logged securely in MySQL with parameterized PDO queries and anti-CSRF protection.
- **Automated Dual Email**: Admin delivery to `contactme@joannastephen.com` and branded autoresponder dispatched to the visitor.

## Tech Stack
- Frontend: HTML5, CSS3, Vanilla JavaScript
- Backend: PHP (8.x) & MySQL
- Bot Defense: Cloudflare Turnstile
